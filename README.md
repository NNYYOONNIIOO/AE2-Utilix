AE2 Utilix was originally an add-on for [AE2 Unofficial Extended Life](https://www.curseforge.com/minecraft/mc-mods/ae2-extended-life), while AE2S Utilix is an add-on mod for [Applied Energistics 2 Supergiant](https://github.com/FormlessDragon/Applied-Energistics-2-Supergiant). The functionality is almost identical, but some duplicate items have been removed.

The following items are included in this mod:

- **Return Bus Card**: Allows an ME Interface to extract finished products from the same face after pushing ingredients.
- **Phase Shifting Card**: Changes the direction in which an ME Interface sends materials.
- **Crystal Growth Chamber**: Performs mixed fluid-item crafting. By default, it can only produce Fluix Crystals. Supports CraftTweaker recipe modifications.
- **Phase ME Interface**: Can be wirelessly bound to machines/containers within 16 blocks.
- **Matter Disintegrator**: Has three modes:
  - **Matter Disintegration Mode**: Instantly breaks all breakable blocks.
  - **Brittle Matter Precision Analysis Mode**: Instantly breaks only glass with Silk Touch precision.
  - **Normal Matter Processing Mode**: Mines blocks at diamond-tier speed.
- **Coupling Wand**: Used to bind the Phase ME Interface. If used to attack an entity, it deals 30 points of custom-type damage that ignores armor and damage reduction.
- **Block Storage Bus**: Can read blocks, dropped items, and containers, and can also write to dropped items and containers.
- **Magnet Card**: Can now be placed into an ME Interface to attract nearby dropped items (configurable).
